Case studies in environmental data science

How to use data to do research in an interdisciplinary fashion

There is a growing demand for people who can work in fields requiring an understanding of ecological data, how to collect it, and how to make sense of it. In this series we’ll cover various methods for how to analyze ecological data, and how to help your students learn it too.

Topics covered

Setting up R and RStudio so you can build and run code on your own machine. Working with existing ecological code to learn how to read, process, and communicate with data. Analyzing and interpreting ecological data. Learn how to generate graphs, statistics, and maps to understand ecological patterns. Learn where to find open data sources in order to run your own projects.

What you’ll get

An understanding of how to build, run, and interpret code with your students. Examples of commented code to use in your own teaching. Where to find data to build your own projects.
